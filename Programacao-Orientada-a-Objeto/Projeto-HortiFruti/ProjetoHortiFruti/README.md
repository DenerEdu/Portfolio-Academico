Projeto Prático Avaliativo — Windows Forms

Desenvolva uma aplicação Windows Forms (.NET Framework) utilizando os conhecimentos adquiridos até o momento.

O sistema deverá utilizar Programação Orientada a Objetos (POO), organização em camadas lógicas MVC e conexão com SQL Server, com um tema escolhido pela equipe, como hotel, restaurante, loja ou locadora.

Requisitos:
Possuir, no mínimo, 5 entidades de cadastro, como Cliente, Produto e Usuário.
Cada entidade deverá possuir, no mínimo, 7 atributos.
Permitir inserção, consulta, atualização e exclusão dos registros de cada cadastro.
Possuir uma tela de seleção de registros para cada entidade.
Possuir, no mínimo, uma tela de movimentação, como Venda, Orçamento, Reserva ou Locação(á definir).
Possuir uma tela principal com menu para acessar as demais telas.

Orientações:
Cuide da organização e da apresentação das telas.
Revise os textos da interface, incluindo ortografia e acentuação.
Organize o código para facilitar sua leitura e compreensão.
Antes da entrega, teste a solução e o script do banco de dados em outra máquina que possua Visual Studio e SQL Server.

Entrega:
A aplicação deverá estar funcionando e sem erros de compilação.
